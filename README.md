## 🛠️ Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
3. Run the application:
   `npm run dev`

## 🤖 AI Architecture

The application uses a server-side Gemini integration so the API key is not placed directly in the browser client.

The main AI experiences include:

- Panda conversational guidance
- Multimodal image/homework assistance
- Study resource search
- Parent observational report generation
